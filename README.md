# Sharp Server · [![CICD](https://github.com/Krossnine/sharp-server/actions/workflows/actions.yml/badge.svg)](https://github.com/Krossnine/sharp-server/actions) [![codecov](https://codecov.io/gh/Krossnine/sharp-server/branch/main/graph/badge.svg?token=RN2I7P8ASR)](https://codecov.io/gh/Krossnine/sharp-server) ![Known Vulnerabilities](https://snyk.io/test/github/Krossnine/sharp-server/badge.svg)

High performance Node.js REST API for image processing using [Sharp](https://github.com/lovell/sharp)

_Note : Work in progress._

## Requirements

| Name | Version |
|------|---------|
| Node | >= 16   |
| Npm  | >= 8    |

## Usage

* `npm install`
* `npm run watch`
* Open your browser at http://localhost:3001

## Deployment using docker

* Simply run `docker-compose up` to build and run Sharp Server
* Open your browser at http://localhost:3001
